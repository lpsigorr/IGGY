# STAR campaign: Gemini prompts, round 1

How to use (free Gemini desktop app):
1. New chat. Attach the files listed for the shot (your photo first, then the flat).
2. Paste the prompt as it is.
3. If the result is close but the print or text is off, reply in the same chat: "Keep everything, only fix the print on the shirt so it matches image 2 exactly."
4. Download the best result at full size and send it to me. I fix lettering where Gemini bends it.

One edit per prompt. Gemini gets worse when you ask for several changes at once, so do the second change on the result of the first.
