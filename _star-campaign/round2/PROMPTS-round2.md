# STAR campaign, round 2: prompts

## Rules for every shot
- One new Gemini chat per photo.
- First message: attach the photo first, then the reference PNG(s) in the order given, then paste the prompt.
- Follow-up passes: stay in the same chat, attach only the new reference PNG and paste the follow-up prompt. Gemini then edits its last result.
- One change per message. Never stack two changes.
- If the garment is right but the lettering of a print is slightly off, keep it. I replace prints with the exact artwork afterwards.
- If something else changed (a face, a hand, the background), reply: "Undo that. Keep image 1 exactly as it was and only change [the item]."
- Download the final version at full size.
